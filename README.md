# 路书

**把联网 AI 查好的行程搬进来，变成一份能带在路上用的东西。**

---

## 下载安装（安卓）

### 方式一：直接装 APK

👉 **[下载 lushu-v1.2.apk](https://github.com/xuelin666/lushu/releases/download/v1.2/lushu-v1.2.apk)**

手机上点开安装。首次需要在系统里允许「安装未知来源应用」。
支持 Android 8.0 及以上，完全离线，不联网。

### 方式二：装成网页应用（不用下载）

手机 Chrome 打开 **https://xuelin666.github.io/lushu/** → 右上角三个点 → 安装应用 / 添加到主屏幕。

体验和 APK 基本一样：独立图标、全屏无地址栏、离线可用。

## 它是干什么的

这个软件**自己不去查资料，也不自己排行程**。它做的是另外一件事：
把联网 AI 查好、排好的结果，变成一份能带在路上的东西，并且在路上真的能用。

为什么这么设计：天气、预约规则、放票时间这些信息每天都在变，
让一个能联网搜索的 AI 去查，比接一堆 API 更省事也更准。
而软件的力气花在 AI 做不了的地方——实时提醒、清单状态、花销记录、足迹。

---

## 怎么用

1. 打开应用，在顶部**填一张行程票**（出发地、目的地、日期、人数、交通、特别要求），
   或者懒得填就用下面那个框写一句话，比如「我们四个人国庆想去江西，开电车，不想太赶」
2. 点生成按钮，软件复制一段提示词
3. 把提示词粘给任意**能联网**的 AI（DeepSeek / Kimi / 豆包 / ChatGPT 都行）
4. 把 AI 的回复**整段**粘回软件，点「解析并载入」

五个界面就按你的行程铺满了。代码块和前后废话都不用删，软件会自己剥。

**出发前两三天**，用「只刷新情报」按钮再问一次，粘回来只覆盖情报屏，其他四屏不动。

---

## 五个界面

| 界面 | 管什么 |
| --- | --- |
| **规划** | 逐日行程、车程、天气、要不要预约；导出日历和行程文字 |
| **情报** | 天气、注意事项、出发前提醒，可自己增删改 |
| **装备** | 出门清单，点方框就计数；可自由增删、改数量、改分组；采购清单和清单模板 |
| **档案** | 随手记：日期、地点、评分、花费、一句话、照片；按月归档；导出图文小册子 |
| **图鉴** | 去过哪些地方，点亮了哪些 |

## 你的数据在哪

**只存在你自己的手机里。** 应用不联网、不上传任何数据。

想备份或换设备，用「导出当前路书」存一份 JSON 文件。

---

## 还没做的

- **推送提醒**：界面上标了「待接入」，需要配一个 ntfy 服务才能真正发到手机
- **轨迹解锁**：要读手机 GPS，得等有原生权限之后再做

## 技术说明

整个应用是**一个 HTML 文件**，界面、素材、逻辑全在里面，约 1.2 MB。
APK 是一个 WebView 外壳，把这份文件装进去，所以改界面不需要动原生代码。

```
lushu-pwa/      网页应用（也是 PWA，可以直接部署）
  index.html    应用本体
  manifest.webmanifest
  sw.js         离线缓存
  icon-*.png
```

想自己打包 APK 的话，`lushu-android/` 里有一套 Capacitor 工程和步骤说明。
